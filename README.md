Optimization (IDS 435)

This repository contains advanced coursework in operations research and quantitative optimization, with a strong emphasis on real-world problem formulation and solver-based implementation. The projects demonstrate the application of mathematical programming techniques to both public-policy and financial decision-making problems using Python and a commercial optimization engine.

The gerrymandering project models electoral district design as a constrained integer-programming problem. Using Gurobi, the model assigns precincts to districts through binary decision variables while enforcing realistic constraints such as population balance and geographic contiguity. The formulation reflects the trade-offs inherent in districting problems and highlights how optimization techniques can be used to analyze and evaluate politically sensitive allocation decisions. The results are visualized using Matplotlib, providing intuitive geographic representations of the optimized district maps and reinforcing the interpretability of the model.

The portfolio optimization project applies modern portfolio theory in a practical investment context. Historical equity price data is retrieved via the EOD HD API and processed using Pandas and NumPy to estimate expected returns and risk measures. The project formulates a mean–variance optimization problem with realistic investment constraints, including sector exposure limits and risk tolerances. Gurobi is used to solve the resulting quadratic program, generating optimal asset allocations and constructing an efficient frontier. Visualizations are produced to illustrate risk–return trade-offs and to support data-driven portfolio selection.

Collectively, this repository demonstrates proficiency in mathematical modeling, constraint optimization, and quantitative finance, as well as hands-on experience with industry-grade solvers. It highlights the ability to translate complex real-world problems into rigorous optimization frameworks and to implement scalable, interpretable solutions using professional analytical tools.
